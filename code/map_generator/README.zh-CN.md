# 图 1 —— 研究区域地图

[English](README.md) · **中文**

绘制双面板图 1：**(a)** 乌苏里江研究河段及 13 个 eDNA 采样点；**(b)** 各采样点在河网中的位置，
以距乌苏里江—阿穆尔河汇口的距离为纵轴。

这是本包中唯一使用 **Python**（而非 R）的部分，因为制图属于绘图任务。其结构分为两部分：

| 路径 | 作用 |
| ------------------ | -------------------------------------------------------- |
| `cartokit/` | 通用、可复用的出版级制图库（见其自带 README 与 LICENSE） |
| `make_figure.py` | 研究专用脚本：站点数据、配色、面板布局与成图 |

本图使用 **`cartokit`** 生成 —— 这是一个由 **Pouria Hadjibagheri** 创建并提供的开源库，依据
PolyForm Noncommercial License 1.0.0 发布：**须署名，且仅限非商业用途**。本目录中的脚本仅包含
研究专用内容；所有制图、出版尺寸换算与标注放置均由该库完成。

## 环境要求

- **Python ≥ 3.12** 与 **Pillow**（`pip install pillow`）。除此之外无需任何依赖 —— 不需要 GIS
  工具链，也不需要联网。
- 一种无衬线 TrueType 字体。脚本依次查找 Arial（Windows）、DejaVu Sans（Linux）与 Helvetica
  （macOS）；若均不存在，则回退到 Pillow 内置字体并给出警告。

## 运行方式

在本目录下：

```sh
python make_figure.py            # 150 dpi PNG 审阅图 + 标注审计
python make_figure.py --print    # 500 dpi TIFF 与 300 dpi PNG（投稿用）
```

结果写入 `../../outputs/`。若审计未通过，脚本以非零状态退出，便于纳入自动检查。

## 输入数据

| 输入 | 提供内容 |
| --------------------------------- | ------------------------------------ |
| `../../data/site_metadata.csv` | 站点编号、名称、河段、经度、纬度 |
| `../../data/site_environment.csv` | Strahler 河流等级与距汇口距离 |
| `../../data/geo/*.geojson` | 裁剪后的陆地、省界、湖泊、河流与城镇 |

底图来源与许可见 [`../../data/geo/SOURCES.zh-CN.md`](../../data/geo/SOURCES.zh-CN.md)。
OpenStreetMap 图层适用 **ODbL**，因此图上的署名行必须保留。

## 符合插图规范

所有尺寸均以**物理单位**声明 —— 字号用磅（pt），标记与间距用毫米（mm），线宽用磅 —— 并相对于
既定出版宽度设定，因此输出严格符合规范：

- 宽 **190 mm**，即通常的通栏（双栏）插图尺寸。
- **所有文字 ≥ 7 pt**，为印刷字号的常见下限；正文标注为 7.5–8.5 pt，同时满足部分出版方关于标注
  高度约 2 mm 的建议。
- 组合图输出 **500 dpi** TIFF，并另出 300 dpi PNG。

宽度、最小字号与分辨率均为 `make_figure.py` 顶部的具名常量，因此更换规范只需改动一行，无需重排。

每条标注均通过 `cartokit` 的冲突避让登记表放置；渲染后脚本会打印**审计**报告，列出任何残余重叠、
被舍弃的标注以及低于下限的字号。运行无误时以 `RESULT: PASS` 结束；空间紧张时可能舍弃经纬网或
湖泊等装饰性标注，这属预期行为并会被报告。

## 约定

标记**形状**与颜色共同承载河段区分，因此身份识别不单独依赖颜色；三种色相取自经色盲校验的分类配色
顺序。重叠标记保留与画布同色的描边环，以保持可分辨。
